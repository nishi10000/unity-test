# unity-test

Unityの動作確認/学習用テストプロジェクトです。

## 概要

Unityプロジェクトの作成、GitHubへのpush、pull requestなどを試すためのリポジトリです。

## 主なディレクトリ

- `Project/Assets/Scenes/` - サンプルシーン
- `Project/ProjectSettings/` - Unityプロジェクト設定
- `Project/Packages/` - パッケージ設定

## 開き方

1. Unity Hubで `Project/` ディレクトリを指定して追加
2. Unityでプロジェクトを開く
3. `Assets/Scenes/SampleScene.unity` を開いて再生

## メモ

テスト用途のため、実装内容は最小構成です。
